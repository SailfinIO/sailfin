# Sailfin Planning Skill

Use this skill to audit, structure, and maintain Linear planning for the Sailfin project.

## Operating Principles

1. Linear is the planning source of truth (Initiatives → Projects → Issues → Cycles).
2. Prioritize production compiler and runtime health: Correctness, Self-hosting, Performance, Runtime safety, Portability, Ergonomics, Release health.
3. Keep issues session-sized (estimates 1, 2, or 3). Anything larger should be split or created as a Project.
4. Align with `docs/conventions/linear-workflow.md` and `docs/status.md`.
5. Require explicit user approval before performing bulk Linear writes.
