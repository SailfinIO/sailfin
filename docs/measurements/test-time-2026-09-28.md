## Fixture work removed

`run_cache_flags_test.sfn` now checks the cold default output in its existing
compatibility invocation and checks both warm trace assertions plus
`--no-cache` within one fixture lifecycle. This removes four nested `sfn run`
calls while keeping the `--no-cache`, `--clean` cache, and `--clean`
staged-tree assertions.
The private `--clean` fixture retains its original two warm runs. The
installed 0.12.0 seed writes cache schema v2 and cannot validate its v3
assertion; the edited file passed with the checkout's self-hosted compiler.

`runtime_demand_driven_sources_test.sfn` checks the staged module ceiling on
the same print-only build that proves crypto is absent. Its reused-scratch
case now runs the net-demanding binary before narrowing the staged set, so
the separate build of that identical net fixture is gone. These changes
remove two nested builds while retaining the manifest, sub-effect,
escape-hatch, diagnostic, and pruning assertions.

Local targeted verification used `sfn dev bootstrap build` followed by
`build/bin/sfn.exe test` on both edited files with `--jobs 2`. All four
cache-flag cases and all six runtime-gate cases passed. These local durations
are not directly comparable with the CI run's per-file times because the
compiler binary, cache state, and concurrent load differ.
